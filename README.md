# ИСКРА — детские праздники

Многостраничный сайт студии детских праздников: программы и цены, персонажи, информация о команде и форма заявки.

## Запуск

```bash
npm ci
npm run dev
```

Локальная версия откроется по адресу `http://localhost:5173`.

## Сборка

Обычная сборка проекта:

```bash
npm run build
```

Статическая сборка для GitHub Pages:

```bash
npm run build:pages
```

Она создаётся в каталоге `out/`, учитывает базовый путь `/detskie-prazdniki` и закрыта от поисковой индексации через `robots.txt` и метатеги `noindex, nofollow`.

## Статическая демоверсия

GitHub Pages содержит все публичные страницы, адаптивную вёрстку, изображения и клиентские взаимодействия. Форма заявки демонстрирует интерфейс и состояние успешной отправки, но не передаёт данные в CRM или почту — интеграция подключается отдельно.
